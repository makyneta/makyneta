**EN** — I'm Tomás Mota, a multidisciplinary creator from Marinha Grande, Portugal. My main focus is **fullstack web development** and **photography** — building digital products from scratch and capturing the world through a lens. When I'm not coding or shooting, I'm setting up stages, designing brands, or fixing computers.
